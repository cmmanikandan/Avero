# 🌟 Avero: Next-Gen Hyper-Commerce Marketplace Engine

Avero is a full-featured, multi-tenant e-commerce ecosystem built with React, Vite, Supabase, and modern web architecture.

## 🚀 Key Modules & Portals
- **🛍️ Buyer Marketplace**: Multi-token search, luxury brand boutiques, smart Apriori bundle engine, live order tracking.
- **📦 Seller Hub (`/seller`)**: Catalog management, bulk CSV import, automated A4 GST tax invoices, T+1 settlement ledger.
- **🚴 Delivery Fleet (`/delivery`)**: Mobile-optimized rider manifest, GPS routing simulation, barcode/QR scanner, and 6-digit OTP delivery handover.
- **🛡️ Admin Governance (`/admin`)**: Real-time GMV streams, seller KYC moderation, commission rules, and banner CMS.

## 🛠️ Tech Stack
- **Frontend**: React 18, React Router v7, Lucide Icons, Canvas Confetti
- **Build Tool**: Vite 5
- **Backend / Database**: Supabase (PostgreSQL & Row-Level Security)
- **Authentication**: Firebase & Supabase Auth adapters
- **Payment Processing**: Razorpay checkout integration
